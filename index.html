Deploy บน
Raspberry Pi 5 / Jetson Orin Nano

คอร์สนี้เน้นการลงมือทำตั้งแต่เก็บภาพ ทำ Dataset เทรนโมเดล จนถึงนำโมเดลไป Deploy บน Edge Device จริง ผู้เรียนสามารถนำโจทย์งานของตัวเองมาทดลองในคลาสได้ (Bring Your Own Use Case)

สิ่งที่คุณจะได้เรียนรู้

  • สร้างและเทรน AI Model ด้วยตัวเอง
  • สร้าง Dataset และทำ Label สำหรับงาน Vision
  • ตรวจจับวัตถุแบบ Real-time
  • นำโมเดลไปใช้งานบนระบบ AI Vision
  • เพิ่มความแม่นยำของ AI Model
  • สร้างระบบ Face Recognition ที่เพิ่มคนใหม่ได้โดยไม่ต้อง Retrain
  • แปลงโมเดล PyTorch → ONNX → TensorRT ให้เหมาะกับ Hardware
  • Deploy ด้วย Docker บน Raspberry Pi 5 และ Jetson Orin Nano
  • เชื่อมต่อผลลัพธ์ AI เข้ากับ MQTT, Node-RED และ Dashboard

อุปกรณ์ที่ใช้ในคอร์ส

Raspberry Pi 5 (4GB RAM)Edge Device สำหรับ Deploy โมเดล
TESR Pi AIoT Gatewayพร้อมชุด I/O และเซนเซอร์
Jetson Orin Nano (8GB RAM)สำหรับงาน Real-time Detection
กล้องสำหรับงาน AI Visionใช้เก็บ Dataset และทดสอบระบบ

อุปกรณ์ทั้งหมดจัดเตรียมให้ใช้งานในคลาส (ไม่รวมในค่าอบรม เว้นแต่ระบุเป็นอย่างอื่น)
